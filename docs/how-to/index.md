# How-to guides

Each guide solves one task. They assume you have already rendered
[your first video](../getting-started/first-video.md).

| Task | Guide |
|---|---|
| Draw a list as bars, and style the bars | [Show a list as bars](bars.md) |
| Show an index, a running total, or an area | [Follow a variable](variables.md) |
| Animate a 2-D grid and a search over it | [Animate a grid search](grids.md) |
| Draw points, hulls and paths | [Draw points and paths](geometry.md) |
| Put your source on screen with a moving highlight | [Show the code](code.md) |
| Pick colours, gradients and palettes | [Choose colours](color.md) |
| Change instruments, scale and loudness | [Design the sound](sound.md) |
| Speed things up, skip events, change how things move | [Control pacing and motion](motion.md) |
| Make a 9:16 video that loops seamlessly | [Make a vertical looping Reel](reels.md) |
| Animate something the built-in views can't | [Write your own view](custom-view.md) |
